# **App Name**: VaultForge

## Core Features:

- Token Crowdsale Portal: A secure interface for ETH-based token participation featuring hard/soft cap validation and administrative whitelist checks.
- Whitelisting Management Tool: Admin dashboard for project owners to securely manage wallet addresses for private seed phases.
- Multi-Tier Staking Hub: Interactive card-based interface for selecting 30, 90, and 180-day lock tiers with calculated APY rewards.
- AI Reward Forecaster: Uses a tool to analyze user staked assets and historical contract performance to predict future reward yields.
- Two-Step Transaction Workflow: A state-managed UI flow that handles the ERC20 'approve' and 'stake' transaction sequence with real-time feedback.
- Real-time Event Sync Pipeline: A high-performance background job system using Redis to synchronize on-chain events with off-chain application states.
- Global Investment Analytics: An API-driven dashboard aggregating Total Value Locked (TVL) and historical investment trends for visualization.
- Wallet Connectivity Interface: Viem/Wagmi powered component for secure wallet connection, balance tracking, and transaction lifecycle management.

## Style Guidelines:

- Primary color: Radiant Indigo (#5271FF) for technical stability.
- Background: Deep Obsidian (#0B0D13) for a high-contrast premium dark mode.
- Accent: Cyber Cyan (#1AB6FF) for active states and success indicators.
- Headline: 'Space Grotesk' for a modern, computerized technical aesthetic.
- Body: 'Inter' for high readability of transactional data.
- Modular dashboard layout utilizing interactive card grids for staking tiers and data-dense metrics.
- Microscopic transitions for price updates and loading states during blockchain confirmations.
- Minimalist line-art icons representing wallet states, tokens, and transaction status.
