# Stratum Web3

This is a Next.js 15 application built with React, Tailwind CSS, ShadCN UI, and Firebase, featuring staking rewards forecasting and enterprise-grade Web3 infrastructure.

## Running on Local Server

To run the application locally on your machine, follow these steps:

1.  **Start the Development Server:**
    Run the following command in your terminal:
    ```bash
    npm run dev
    ```

2.  **Access the Application:**
    Once the server is running, open your web browser and navigate to:
    [http://localhost:9002](http://localhost:9002)

    *Note: The application is specifically configured to use port 9002.*

## Key Features

- **Multi-Tier Staking Hub:** Secure your tokens with different lock periods and APY tiers (30, 90, 180 days).

- **Token Crowdsale:** Secure participation in verified seed and private rounds with automated vesting logic.
- **Admin Dashboard:** Comprehensive whitelist management and protocol setting controls for DAO operators.
- **Protocol Analytics:** Real-time visualization of Total Value Locked (TVL) and user adoption metrics.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS + ShadCN UI
- **Database/Auth:** Firebase (Firestore & Authentication)
- **Charts:** Recharts
