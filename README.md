# Stratum Web3

This is a Next.js 15 application built with React, Tailwind CSS, ShadCN UI, and Firebase, featuring AI-powered staking rewards forecasting.

## Getting Started

To run the application in your development environment:

1.  **Start the Development Server:**
    ```bash
    npm run dev
    ```
    The application is configured to run on port **9002**.

2.  **Access the App via URL:**
    - **In Firebase Studio:** Use the integrated preview window on the right.
    - **In a Local Browser:** Navigate to [http://localhost:9002](http://localhost:9002).

## Key Features

- **Multi-Tier Staking Hub:** Secure your tokens with different lock periods and APY tiers.
- **AI Reward Forecaster:** Uses Genkit and Gemini 2.5 Flash to predict yields based on protocol analytics.
- **Token Crowdsale:** Participate in verified seed and private rounds.
- **Admin Dashboard:** Manage whitelists and project settings.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS + ShadCN UI
- **Database/Auth:** Firebase (Firestore & Authentication)
- **AI Integration:** Genkit + Google Generative AI
